# Contributing

Thank you for helping improve MUNI-LCC.

* **Report a problem or ask a question:** open an issue at https://github.com/Olumide-Akindipe/muni-lcc/issues. Include the project file (with any sensitive values removed), the command you ran, and the output.
* **Propose a change:** fork the repository, create a branch, add or update tests in `tests/`, run `python -m pytest`, and open a pull request describing the change and the method source it follows (guideline, section, and edition).
* **Method changes** must cite the public source they implement. Paywalled standards are implemented from public descriptions only; do not paste their text.
* **Conduct:** be respectful and constructive. The maintainer may close issues or pull requests that are not.
