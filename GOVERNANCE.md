# Governance

## Roles
* **Maintainer:** Stephen Olumide Akindipe (ORCID 0000-0002-1846-9662). The maintainer reviews and merges contributions, sets release scope, and makes final decisions on methods.
* **Contributors:** anyone who opens an issue or pull request under CONTRIBUTING.md.

## How decisions are made
* Method changes must cite the public source they implement, by document, section, and edition. Where a guideline states a value (for example FEMP M&V Guidelines v5.0), that value is the default; where it states none, the source of the default is named in the configuration file.
* Proposed changes are discussed in a public issue before significant work begins. The maintainer records the decision and its reason in the issue.
* Changes that alter published results require a test and a CHANGELOG entry, and the worked example must still reproduce or its change must be explained.

## Releases
* Versions follow Semantic Versioning. Each release is tagged on GitHub and archived on Zenodo with a DOI.

## Continuity
* If the maintainer can no longer maintain the project, the repository will be marked as archived and the final release will remain available on Zenodo. Additional maintainers may be added by the maintainer; the change will be recorded in this file.
